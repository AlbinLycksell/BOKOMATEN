# Marketing UI kit

Verkstad marketing surfaces — pleo-editorial, Klarna-grid, type-led where image is wrong.

## Files

- `index.html` — runnable composition: home page (hero + signal pricing tease + voice section + footer)
- `Hero.jsx` — type-led hero. The headline IS the design.
- `TopNav.jsx` — sticky navy nav with wordmark + 3 links + CTA pill
- `PriceCard.jsx` — Pleo-style price card, no "request a demo" wall
- `QuoteBlock.jsx` — pull-quote on linen, Magnus's actual voice
- `Footer.jsx` — restrained navy footer

## Caveats

- Imagery is placeholder SVG framed in 3:2. The user must drop in the production photographer's brief output (Magnus's panelbil, hand on faktura, etc).
- No "Trusted by" logo wall — none was named in the brief and inventing logos would be slop.
