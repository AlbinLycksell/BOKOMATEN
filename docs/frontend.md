# Frontend

Next.js 15 (App Router, Turbopack) · React 19 · TypeScript strict · Tailwind CSS v4 · pnpm. Lives in `web/`.

## Design language — Nordic restraint

The aesthetic: warm off-white surfaces, hairline borders, deep forest accent, generous whitespace, tabular numbers. Depth comes from **tone shifts** (`--color-surface-2`, `--color-surface-3`) and **borders**, never from drop shadows.

### Forbidden

> **No drop shadows. Anywhere.** Tailwind's `shadow-*` utilities are overridden to `none` in `globals.css` `@theme`. If a layout looks flat, give it a hairline border on a slightly different surface tone — that is the language of this product.

### Typography

Inter Variable, loaded via `next/font/google`. Tabular numerals everywhere via `font-variant-numeric: tabular-nums`. OpenType features: `cv11`, `ss01`, `ss03` for the Inter "Geist-ish" feel.

## Component patterns

### Owned primitives only

We don't pull `shadcn/ui` via CLI. We keep the patterns and own the source under `components/ui/` so:
- We can strip drop shadows confidently.
- We don't ship surface area we don't use.

### Server component default

Every page in `app/` is a Server Component unless interaction forces `"use client"`. When a child needs interactivity, prefer **leaf** client components (e.g. `FilterBar`, `AudioPlayer`, `NavLink`). Pass elements (JSX) across the server→client boundary, not component references — Next.js's RSC serializer rejects functions.

### Adding a view

1. Create `app/(app)/<route>/page.tsx`. Server Component by default.
2. Use `Topbar` for the page header — title, description, optional actions.
3. Compose with `Card`, `CardHeader`, `CardTitle`, `CardContent`. No shadows.
4. Data lives in server-component `await` calls to `lib/api.ts`. Wrap in try/catch and render a graceful empty state.
5. Localize copy in Swedish — Inkorg, Bokningar, Inställningar.

### Adding a primitive

`components/ui/<name>.tsx`, `forwardRef`, variant + size record types, `cn(...)` for class composition, no shadow utilities. Export both the component and (when relevant) variant/size types.

## Generated types

`lib/api-types.ts` is regenerated by `pnpm gen:api` after the backend's `uv run dump-openapi`. Components must import flat aliases from `lib/api-models.ts`, never directly from `api-types.ts` — this insulates us from generator format changes.

## Running locally

```bash
cd web
pnpm install
pnpm dev   # http://localhost:3000
```

`/api/*` requests are rewritten to `http://127.0.0.1:8000/api/*` via `next.config.ts`, so the backend on port 8000 is transparent.

## Build verification

```bash
pnpm typecheck   # tsc --noEmit
pnpm build       # full Next.js production build
```

Both pass in MVP. New code should keep both green.
